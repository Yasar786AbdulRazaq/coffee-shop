

# ☕ Coffee Heaven

Coffee Heaven is a simple and interactive web application built using **Streamlit**. It simulates a coffee shop experience where users can view a menu, order coffee, learn about the shop, and contact the team — all from an elegant interface.

---

## 🚀 Features

- 🏠 **Home Page**: Welcome screen with a banner and introduction.  
- 📋 **Menu**: Displays coffee options with images, descriptions, and prices.  
- 🛒 **Order Form**: Collects user details for placing coffee orders.  
- 👨‍💼 **About**: Describes the story and values of Coffee Heaven.  
- 📞 **Contact Page**: Lets users send a message and get in touch.  

---

## 🛠️ Built With

- **Python 3**
- **Streamlit**
- **Pillow (PIL)** for image handling

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Yasar786AbdulRazaq/coffee-heaven
cd coffee-heaven
```

2. Install the required libraries:

```bash
pip install streamlit pillow
```

3. Run the app:

```bash
streamlit run app.py
```
